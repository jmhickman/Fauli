# Fauli

Authentication solver for Active Directory environments. Given credentials, host details and a protocol, Fauli determines the appropriate authentication method and produces an authenticated network connection plus other details needed to utilize the connection.

Supports Kerberos and NetNTLMv2 across SMB, LDAP, 

Future support planned for authentication: OAuth 2.0, SAML and user certificates.
Future support planned for protocols: WinRM, RDP, HTTP, MSSQL, DNS, RPC, and Exchange.
